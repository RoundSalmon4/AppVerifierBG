# AppVerifier BG Privacy Policy

This app does not connect to the internet on its own and requires no
network permissions. The "View source code" button in settings opens
the project's GitHub page in your default browser.

This app does not collect, transmit, or share any personal data. All
processing is performed locally on your device.

## Installed apps

This app can see which apps are installed on your device in order to
display information about them and verify their signatures. This
information is used only while the app is running and is not stored or
transmitted.

## Verification and clipboard

Verification info for an individual app can be shared or copied to other
apps using the share and copy buttons. You can also verify an app by
pasting verification info from your clipboard or by sharing verification
info received from others to this app. Clipboard content and text shared
to this app are not stored — they are used only to check whether the
given package name and hash match the selected app, and are then
discarded.

## APK files

If you provide an APK or .apks file to this app, it is temporarily stored
in this app's cache directory and deleted once the needed signature
information has been processed. For .apks containers, the base APK is
extracted and also deleted after processing.

## User database

You can save app verification entries to a user-created database. These
entries consist of package names and signature hashes. They are stored
persistently on your device and remain until you delete them or clear
the app's data. You can view, export, or delete entries at any time
through the settings screen. Export writes a file to a location you
choose via the system file picker; import reads a file you select
through the same mechanism. No third party has access to this data.

## Clipboard checkmark

When clipboard verification succeeds, the verified package name is
stored locally so a checkmark can be displayed in the app list. This
list persists until you clear it through the settings screen or clear
the app's data.

## Data retention

User database entries and clipboard-verified package names are kept
until you delete them or clear the app's data. APK file copies are
deleted immediately after processing. All other data is ephemeral and
exists only in memory during use.

## Your rights

Because all data is stored locally and under your control, you can
exercise any data rights — including access, rectification, and
erasure — directly through the app's user interface. You do not need
to contact anyone to modify or delete your data.

## Contact

If you have questions about this privacy policy, you can open an issue
at: https://github.com/RoundSalmon4/AppVerifierBG

## Changes to this policy

This privacy policy may be updated from time to time. When it does, you
will be prompted to accept the new policy upon opening the app.
